## 3. Что нужно конвейеру

| пункт | состояние | оценка |
|---|---|---|
| Получение: ESO (TAP + SODA-вырезка галактики + карта весов) | **код**: `fetch` сейчас только MAST; обходной путь — файлы вручную в `data/inbox/<объект>/` (есть) | 0,5–1 день; вручную — сразу |

| Чтение: DECam instcal (60 чипов), Pan-STARRS asinh-кодировка | код | 1 день / 2 ч (не нужны при выборе ESO) |
| Фильтры: `g_SDSS`, `r_SDSS`, `i_SDSS`, `u_SDSS`, `NB_659`, DECam «g DECam SDSS c0001 …» | **код**: `filters.normalize_filter_name` принимает только F###, `mission` — только jwst/hst; нужен реестр наземных полос с длинами волн и `mission: ground` | 0,5 дня |
| Палитра: u фиолетовый, g синий, r зелёный, i красный | правка конфига (`color.overrides`) | — |
| Hα: узкая полоса содержит континуум — вычесть r (Hα − k·r) и наложить красным | код (k по звёздам поля) | 0,5–1 день; без вычитания — конфиг, но звёзды розовые |
| Космические лучи | не нужно: тайлы и стеки уже очищены (код 3b — для одиночных кадров) | — |
| Единицы и нуль: Jy или ADU/с + AB, DECam `MAGZERO` | для showcase не нужно (растяжка по фильтру); для баланса по потоку — код (масштаб по нулю) | 2 ч |

Минимум для первой наземной галактики из ESO: реестр наземных фильтров и `mission: ground` (код, 0,5 дня), данные вручную в `inbox` (вырезка SODA — один запрос на полосу), конфиг. Получение ESO в `fetch` — следом, чтобы прогон воспроизводился командой.

## 4. Рекомендация: ESO Fornax Deep Survey + NGC 1365

- **Глубина и качество:** u/g/r/i по 11,6–42 тыс. с — глубже всех наших вариантов кроме DECam M83/Cen A, при этом готовый сложенный тайл на полосу, а не сотни кадров разных программ.
- **Фон:** обзор сделан для слабых протяжённых структур — фон вокруг галактики не «съеден», в отличие от Legacy Survey и стеков DECam (лист 01).
- **Одна сетка 0,2″/px, WCS, абсолютная калибровка AB, PSF 1,1″; насыщение точечных источников с 15,4 зв. вел.** (в ARP_VST у Cen A — уже с 18,5). Активное ядро NGC 1365 может дать плато в центральных пикселях — проверить на вырезке; рукава насыщения не дадут.
- **Поле:** b = −54°, мало звёзд переднего плана; галактика 11′ — вырезка 25′ ≈ 7500² px, 0,2 ГБ на полосу.
- **Доступ:** без аккаунта, CC BY 4.0 (совместимо с нашей CC BY-SA), SODA-вырезка на сервере, 4 запроса.
- **Картинка:** классическая спираль с перемычкой, на превью Legacy чистая.

Следующей — **Cen A + ESO ARP_VST** (g/r/i + Hα 36 тыс. с): красивее и сложнее — насыщенное ядро, тысячи звёзд, вычитание континуума из Hα. M83 из DECam — самая глубокая, но это сведение сотен стеков разных программ и агрессивный фон пайплайна.
